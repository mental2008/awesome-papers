## Papers

### Large Language Models (LLMs)

* KV Cache Management
  * KVCache Cache in the Wild: Characterizing and Optimizing KVCache Cache at a Large Cloud Provider \[[Paper](https://www.usenix.org/conference/atc25/presentation/wang-jiahao)] \[[Trace](https://github.com/alibaba-edu/qwen-bailian-usagetraces-anon)]
    * SJTU IPADS & Alibaba Cloud
    * Key takeaways from the characterization study
      * KV$ reuses are common, but the reuse ratio is smaller than previously reported numbers on synthetic datasets.
      * For each specific request category, the reuse time is predictable based on the historical information.
      * The lifespan of KV$ is ephemeral.

### GPU Sharing

* Efficient Performance-Aware GPU Sharing with Compatibility and Isolation through Kernel Space Interception \[[Paper](https://www.usenix.org/conference/atc25/presentation/zhang-shulai)]
  * SJTU & Lenovo
  * **Krypton**
  * The hardware units are divided using MIG, while time slices and device memory are allocated using kernel-space scheduler.
* GPreempt: GPU Preemptive Scheduling Made General and Efficient \[[Paper](https://www.usenix.org/conference/atc25/presentation/fan)] \[[Code](https://github.com/thustorage/GPreempt)]
  * THU
  * Implement a timeslice-based yield mechanism to enable context-switch preemption on GPUs.
  * Employ a hint-based pre-preemption technique to overlap the preemption process with the essential data-preparation phase.
* Colocating ML Inference and Training with Fast GPU Memory Handover \[[Paper](https://www.usenix.org/conference/atc25/presentation/wang-jiali)] \[[Code](https://github.com/SiriusInfTra/Sirius)] \[[Slides](https://www.usenix.org/sites/default/files/conference/protected-files/atc25_slides_wang_jiali_0.pdf)]
  * SJTU IPADS
  * Key insight: training task is elastic and reconfigurable; transfer memory between training and inference by reconfiguring training tasks (i.e., changing batch size)
